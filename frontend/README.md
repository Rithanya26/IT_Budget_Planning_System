IT Budget Planner System

A full-stack web application to automate IT budget management, expense tracking, forecasting, and cost optimization for organizations.

This system replaces manual Excel-based budget handling with a secure, role-based, real-time solution using modern web technologies.

🚀 Features
🔐 Authentication & Roles

Role-based login using username & password

Two roles:

Admin (Finance/IT Manager)

Department User

🧑‍💼 Admin Functionalities

Create and manage departments

Create department users and assign them to departments

Allocate monthly/yearly budgets

View all department expenses

Monitor total IT spending

Identify over-budget departments

Alerts at:

80% budget usage (warning)

100% usage (over-budget)

Visual dashboards:

Bar chart (Budget vs Actual)

Pie chart (Cost distribution)

👨‍💻 Department User Functionalities

View assigned department automatically

Add IT-related expenses:

Cloud services

Software licenses

Hardware

Maintenance

View:

Budget

Total spent

Remaining balance

Alerts & warnings

Dashboards:

Line chart (Monthly expense trend)

Budget usage percentage

📈 Forecasting Module

Uses last 3 months expense average

Predicts:

Next month expense

Yearly estimation

Displays forecast using charts and text

💡 Cost Optimization

Detect repeated high cloud costs

Track unused software licenses

Suggest reduction of unused licenses
